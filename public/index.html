    🔌 Connect Your Agents & IDEs

    Connect Claude Code via native lifecycle hooks. Automatically tracks tool execution, alerts you when Claude waits for input, and optionally gates Bash commands from your panel or phone.

    Auto-configure ~/.claude/settings.json 
    node ./bin/incontrol.js setup claude-code --install
    Or add to ~/.claude/settings.json manually 
    {
  "hooks": {
    "PreToolUse": [{ "matcher": "*", "hooks": [{ "type": "command", "command": "incontrol hook claude PreToolUse" }] }],
    "Notification": [{ "matcher": "", "hooks": [{ "type": "command", "command": "incontrol hook claude Notification" }] }],
    "Stop": [{ "matcher": "", "hooks": [{ "type": "command", "command": "incontrol hook claude Stop" }] }]
  }
}

    Connect Antigravity, Cursor, Windsurf, VS Code, or Claude Desktop via the built-in MCP server. Gives your IDE agent incontrol_status and incontrol_ask_human tools.

    MCP Server Configuration (mcp_config.json / .cursor/mcp.json) 
    {
  "mcpServers": {
    "incontrol": {
      "command": "node",
      "args": ["/path/to/InControl/bin/incontrol.js", "mcp", "--ide", "Cursor"]
    }
  }
}

    Wrap any terminal coding agent (Codex, Aider, OpenCode, Gemini CLI). InControl streams output, detects interactive [y/n] prompts, and pipes your remote replies directly into the terminal’s stdin.

    Wrap any CLI agent 
    # Wrap OpenAI Codex CLI
incontrol wrap --name "Codex" --ide "Ghostty" -- codex

# Wrap Aider
incontrol wrap --name "Aider" --ide "iTerm2" -- aider

# Wrap OpenCode
incontrol wrap --name "OpenCode" --ide "Warp" -- opencode

    Connect any custom agent (Python, TypeScript, LangGraph, CrewAI, bash scripts) with a single HTTP call or the zero-dependency SDK.

    Ask Human & Wait for Response (cURL / Webhook) 
    curl -X POST http://localhost:4747/api/agents/ask \
  -H "Content-Type: application/json" \
  -d '{
    "id": "my-custom-bot",
    "name": "DeployBot",
    "ide": "Python SDK",
    "workspace": "/repo/backend",
    "question": "Approve production Kubernetes rollout?",
    "command": "kubectl rollout restart deployment/api",
    "options": [
      {"id": "approve", "label": "Rollout Now", "style": "primary"},
      {"id": "deny", "label": "Abort", "style": "danger"}
    ]
  }'
